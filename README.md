# COVID-19 India Vaccination Dashboard (Excel)

## 📌 Project Overview

This project is an interactive COVID-19 India Vaccination Dashboard built using Microsoft Excel. The dashboard analyzes vaccination progress across Indian states using Pivot Tables, Pivot Charts, KPI Cards, and Slicers.

## ✨ Features

- Interactive State-wise Slicer
- KPI Cards
- Total Vaccination Analysis
- Dose 1 vs Dose 2 Comparison
- Population Analysis
- Vaccination Percentage Analysis
- Business Insights

---

## 📈 Business Insights

- Uttar Pradesh recorded the highest vaccination doses.
- Vaccination doses show a strong positive relationship with population.
- Most states achieved vaccination coverage above 150%.
- Precaution doses remain significantly lower than Dose 1 and Dose 2.
